# Aishwarya Birthday Website — Countdown Edition 🎀

## What happens

The main link opens `index.html`, which is a cute pink countdown page.

The countdown targets **21 September 2026 at 12:00 AM IST (India)**.

Before that time:
- The birthday page remains locked.
- The "Open Birthday Surprise 🎂" button is disabled.

At/after that time:
- The countdown becomes zero.
- The button unlocks.
- Clicking it opens `birthday.html`.
- `birthday.html` contains the animated cake, candles, letter, 4 photo memories, popup cards and final confetti surprise.

## Add your photos

Replace:
- `photos/photo1.jpg`
- `photos/photo2.jpg`
- `photos/photo3.jpg`
- `photos/photo4.jpg`

Keep the same filenames.

## Share it as a link

For an actual shareable web address, upload the whole folder to a static website host. The file to use as the main page is `index.html`.

## Important

The countdown is based on the visitor's clock and the fixed India timezone target. A determined person could still directly visit `birthday.html`; this setup is intended as a fun countdown/experience rather than security protection.
