# Aishwarya Birthday Website 🎀

A fully animated, scroll-driven birthday page for Aishwarya Jain (21 September).

## How to use

1. Open `index.html` in a browser.
2. Put your four photos in the `photos` folder and name them:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
3. Refresh the page.

## The experience

- Pink/pastel girlish birthday theme
- Scroll-triggered cake entrance
- Five animated candles that light and then extinguish
- Smoke effect after the candles go out
- Animated birthday letter
- Four photo Polaroids with different entrance motions
- Floating birthday popup cards
- Final birthday section
- Surprise button with confetti overlay
- Responsive/mobile-friendly layout

Tip: For best results, use portrait or square photos. JPG/PNG both work if you update the file names in `index.html`.
